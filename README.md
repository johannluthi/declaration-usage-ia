# Déclaration d'usage de l'IA

Page web qui permet à un·e étudiant·e de construire sa fiche de déclaration des usages de l'IA à partir de la « Grille d'analyse des usages d'IA » (Johann Lüthi, Faculté des géosciences et de l'environnement, Université de Lausanne) : 8 activités, 5 niveaux d'intégration.

- Page : https://johannluthi.github.io/declaration-usage-ia/
- Français et anglais.
- Export PDF (par la fenêtre d'impression du navigateur) et Word (.docx).
- Un seul fichier, `index.html`, sans dépendance. Aucune donnée n'est transmise : les réponses restent dans le navigateur.

Pour adapter la grille (activités, niveaux, libellés), modifier les constantes `LEVELS`, `ACTS` et `T` au début du script de `index.html`.

Cette page n'est pas une publication officielle de l'UNIL.

La grille vierge est aussi disponible en Word, modifiable : `grille-usage-ia.docx` (français) et `ai-usage-grid.docx` (anglais). Les deux fichiers reprennent les niveaux, la description par activité et la grille de déclaration d'usage avec des cases à cocher cliquables.
